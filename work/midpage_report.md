# Mid-page portrait changes

A `{ctl.F4}` landing after text with no `{ctl.FD}` / `{ctl.F5}` / `{ctl.F7}` /
`{ctl.FC}` since swaps the portrait **while the current line is still on
screen**. `{ctl.FD}` is a layout token, so every one of these is ours to
change in either direction.
